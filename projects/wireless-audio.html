Multi-Zone Wireless Audio System

Deployed a fleet of Raspberry Pi devices to create a multi-zone wireless audio system for the Tulane MakerSpace.

Context MakerSpace Work
Date Spring 2026

Project Overview

This project was started to improve the audio system in the MakerSpace. The previous system was fully hardwired and required the audio playing device to be directly next to the speakers. Additionally, the user was only able to play audio from one set of speakers at a time, and not synced throughout the entire MakerSpace. This is unideal for a space where people are constantly moving between different areas while working on a project.

My solution to this issue was to connect a Raspberry Pi to each set of speakers. Each Raspberry Pi has the Shairport Sync package installed, which enables each Pi to be discoverable as an AirPlay 2 enabled WiFi speaker. This allows MakerSpace users to wirelessly cast audio to either a single zone, or multiple zones at once.

This architecture and deployment also allows future MakerSpace employees to easily add more zones in the future.

Technical Details

Hardware

  • Raspberry Pi fleet
  • USB/3.5mm audio output
  • Existing speaker systems

Software

  • Shairport Sync
  • AirPlay 2 protocol
  • Raspberry Pi OS

Features

  • Multi-zone audio sync
  • Wireless casting
  • Scalable architecture
